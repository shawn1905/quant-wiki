### 内容简介

本专著为**“海外经典量化期权理论”**与**“中国本土商品/股指期权实战”**的集大成合并版知识库。

全书分为四大核心支柱：
1. **中国商品期权实战五层架构**：以波动率为核心第一决策变量，阐释 Orange 双击机制（Vega+Gamma 双击）、五维隐波诊断、五层信号金字塔、决策树与三大策略族、权利金 -50% 硬止损风控铁律，辅以四大真实战例。
2. **逐章观点速查与复盘导读**：提炼实战交易中的核心铁律、参数阈值与思维模型。
3. **西方经典期权书籍理论框架**：直接提取 Sinclair、Natenberg、Augen 等 4~5 本期权圣经的核心逻辑，系统解析 IV vs RV、Close-to-Close / Parkinson / Garman-Klass 波动率估计器、方差溢价（VRP）经济学、Greeks 实战动态管理与 GEX 做市商微观力学。
4. **学术实证与预测指标文献综述**：针对期权偏度（Skew / Smirk）、认沽认购比（PCR）及做市商 Gamma 暴露（GEX）对标的前向预测能力的 20 余篇国际顶级金融学期刊（RFS, JFE, JFM）实证文献综合评述。
